한 세션 전체를 자동으로 묶지 않습니다. 사용자가 검토할 로그를 고르면 AI는 제한된 요약만으로 기존 작업 편입과 신규 작업을 제안하고, 실제 반영은 사용자가 확정합니다.

작업 지도 · 사용자 연결
